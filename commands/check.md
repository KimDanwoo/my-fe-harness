사용자가 구조 규칙이 실제 코드에서 지켜지고 있는지 확인하고 싶어 한다.
규칙은 설치 시점에 주입되지만 코드는 그 뒤로 계속 자라므로, 코드를 되읽어 확인해야 한다.

1. 점검을 실행한다:
   ```bash
   node "${CLAUDE_PLUGIN_ROOT}/bin/my-fe-harness.mjs" check --target .
   ```
2. 보고되는 위반은 세 가지다. 전부 결정론적 판정이며 스타일 취향이 아니다:
   - **아래→위 import** — 하위 레이어가 상위 레이어를 참조(의존 방향 역전)
   - **같은 레이어의 다른 슬라이스 직접 import** — 결합 시작 신호
   - **슬라이스 내부 deep import** — 공개 API(배럴) 우회
3. 위반이 있으면 종료 코드 1이다. 각 항목을 `파일:줄`로 열어 실제 코드를 보고,
   해당 구조 규칙(`.claude/rules/`의 `fsd.md`·`feature-based.md`·`layered.md`)에 맞게 고친다.
   대부분은 **상위 레이어에서 조합**하거나 **공통 부분을 하위로 내리는 것**으로 풀린다.
4. 고칠지 말지는 사람이 판단한다 — 이 명령은 볼 곳을 좁혀줄 뿐 자동 수정하지 않는다.
